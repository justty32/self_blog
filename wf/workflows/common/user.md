# user — 使用者偏好與確認邊界

[common](README.md)

使用者表達可持續適用的偏好時更新本檔；一次性指示留在當次任務。Done when：設定與使用者最新指示一致，沒有互相矛盾的舊值。

| 項目 | 設定 |
|------|------|
| 語言 | 回覆與專案文件使用繁體中文；保留程式識別字與必要技術名稱 |
| 時區 | Asia/Taipei，與 hugo.toml 一致 |
| 分支 | 主線為 main；文章發布腳本只接受 main，其他分支策略未另訂 |
| 執行方式 | 盡量交由 agents 完成編輯與驗證，允許 agents 呼叫子 agents；除簡單工作與雜務外，各 agent 工作前須先通讀 `wf/` 規矩，分工避免同時改同一檔；模型依任務與當次可用項目選擇 |
| 確認邊界 | commit、push 與發布依當次使用者授權處理；2026-10-27 起本次網站開發已授權必要的 commit、push 與部署，該授權範圍持續有效，不重複確認；不延伸至無關任務 |
| 回覆風格 | 見 [reply-style](reply-style.md) |
| 網站美術 | 青藍科幻與未來感；低調奢華、內斂、層次豐富，細節與互動可多，但特效不喧賓奪主 |
| 日常閱讀 | 字要大、對比清楚，讓日常閱讀更輕鬆；每種美術風格都可獨立切換日間／夜間模式 |
| 配色控制 | 可切換美術風格；每種風格的日／夜模式各有六個可調基準色，統一衍生全站配色，讓使用者日後自行調整 |
| JavaScript | 2026-10-27 明確允許 JavaScript，覆蓋原零 JavaScript 規定；預設保持輕量，沉浸互動與更豐富的奢華特效各有明確開關，並保留減少動畫選擇 |
| 互動層次 | 增加 hover、元件動畫與可拖曳光場；開啟奢華時連動開啟沉浸，關閉奢華保留沉浸，關閉沉浸則全部關閉 |
| 奢華模式 | 使用者明確要求全頁背景、文字與玻璃面板一起動，包含 3D、景深、水波等完整效果；啟用後優先完整畫質與豐富層次，可使用較多運算資源，普通模式仍保持輕量且可關閉特效 |
| 風格差異 | 特效也須隨風格變化，不能只換色：光網偏光速、電路與掃描，深空偏星雲、引力與星軌，閱讀偏墨流、紙片與水紋；日間重折射，夜間重發光 |
| 體積 | 整站盡量低於 5 MB、最好低於 10 MB，不能超過 30 MB；目前建置預算採 5 MB |

授權與偏好來源（2026-10-27）：「事情盡量都交給agent做，啥模型都隨你。agent工作前也需要讀過wf/規矩，除非是簡單工作和雜活。agent也可以呼叫子agent。可以隨意push和佈署。」授權範圍依同次指示的網站開發工作解讀，包含完成 push 與部署所需的提交。
