# write — 文章與文件產出

[WORKFLOWS](../WORKFLOWS.md)｜[INDEX](../INDEX.md)

寫文章、README、技術文件、翻譯或改稿時使用；一兩句即時回覆直接回答。

## 流程

1. 確認讀者與目的，依使用者已提供的內容決定骨架；缺少會影響成品的資訊才詢問。
2. 依 [writing](common/writing.md) 寫完整初稿，再修結構、語氣與事實。
3. 數據、引言與可核對的外部事實附來源，優先一手資料；翻譯與改寫維持原意。
4. 發布用文章遵循 [作者指南](../../docs/AUTHORING.md) 的路徑、front matter、圖片與草稿規則；依 [testing](testing.md) 執行網站檢查。
5. 回報成品與驗證結果；發布腳本會 commit／push，須依當次授權執行。

## Done when

成品涵蓋要求的小節、來源可查、無佔位內容；文字精簡且原意保留，適用驗證通過。跨 session 未完成的稿件與待查事實記入 [SESSION-LOG](../SESSION-LOG.md)；真正需要使用者處理的項目記入 [WAIT_USER](../WAIT_USER.md)。
